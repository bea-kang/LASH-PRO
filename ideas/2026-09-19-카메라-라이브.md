# 2026-09-19 카메라 라이브

## 원문 (예빈)
셀카 업로드가 아니라 폰이나 노트북 카메라를 켜고 눈을 대면 바로 보이는 형태였으면 좋겠음.

## 리뷰
- 방식 3개: A 실시간 파라미터 AR / B 카메라+자동캡처+생성 / C 실시간 생성. C는 지연·원가로 제외.
- A가 의외로 잘 맞음: 속눈썹 디자인은 원래 래시 맵(컬·구간별 길이·볼륨)이라 레퍼런스를 파라미터로 번역 가능. 번역된 맵은 원장의 시술 사양이 됨.
- A 리스크: 게임 캐릭터 느낌, 무쌍·속쌍 눈꺼풀 가림, 에셋 제작 노동.
- 결정: Phase 0에서 A·B 둘 다 만들어 같은 5명 평가로 결정. 예상은 A 라이브 + B 정밀 결과 조합.
- 배포 영향: 인앱 브라우저(인스타·카톡)에서 카메라 차단 → "브라우저로 열기" 단계 이탈 발생. Phase 1에서 측정, 심하면 앱.

→ 반영: 01-concept(플로우·차별점), 03-mvp(Phase 0 비교·기술), 05(로드맵·에셋 비용), 06(결정 번복 기록)
