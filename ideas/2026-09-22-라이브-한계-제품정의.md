# 2026-09-22 라이브 한계 → 제품 정의

## 원문 (예빈)
- "딱 봐도 이상하잖아, 모델을 올리던가 해결책 있어야지"
- "둘 다(C, D) 퀄리티는 별로야"
- "우리 이거 어떻게 해결할까"

## 경과
- C(픽셀 이식): 뿌리 그림자·피부 프린지·눈썹 유입·한쪽 눈 반전·조명 불일치 순서로 잡음. gpt-5.5 2차 점 검출로 자동 점이 쓸 만해짐. 가까이+밝은 조건에서 "내 눈 같긴 하다", 구조(스파이크·캣 스윕)는 비슷, 질감은 부족.
- D(가닥 구조 추출 → 새로 그림): 구조 추출은 되나 렌더링이 선 긋기 수준. 질감(끝단·음영·뿌리 가림·광택) 없음.
- 멀리(눈 ≤100px)·어두운 조건에선 어느 방식도 스티커. 이건 방식 문제가 아니라 조건 문제 → 제품에서 막아야 함.

## 결정
- 라이브 = 고르는 화면(C), 캡처 = 결과물(B 생성형). 실시간 사진급은 범위 밖.
- 남는 일은 렌더링 연구가 아니라 B의 재해석 줄이기(측정 가능).

## 배운 것
- "실시간 + 사진 그대로 + 사진급"은 셋 다 동시에 못 가짐. 둘을 고르면 됨: 실시간+구조(라이브), 사진급+정지(캡처).
- 비전 LLM 좌표는 크롭 2단계 + 상위 모델(5.5 low)로 실용 수준. 모델 등급보다 크롭이 더 큼.
- 사용자 테스트는 반드시 실제 사용 조건(가까이·밝게)으로. 최악 조건으로 판단하면 방향을 잘못 잡음.
