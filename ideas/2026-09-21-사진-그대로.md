# 2026-09-21 사진 그대로 가져오기

## 원문 (예빈)
- 프리셋에 추가하는 개념이 아니어도 될 것 같음. 지금은 MVP가 사진의 속눈썹을 얼마나 사진으로 정확하게 가져오느냐가 되어야 함.
- (A 테스트) 눈 감았을 때 감은 느낌 반영이 안 돼서 잘못 붙인 속눈썹을 유지하는 느낌.
- 포트폴리오 사이트에 개인 프로젝트로 올리고 실험 결과를 블로그처럼 (퍼널별 마케팅 / 구현 / 접근 / 셀링) 쓰고 싶음.

## 리뷰
- Phase 0 판정이 나온 것. A(파라미터 AR)는 "내 눈 같다"에 못 미침 → B(사진 기반 생성)로 MVP 본체 이동.
- 깜빡임은 A의 구조적 한계(눈꺼풀 가림·가닥 눕힘을 실시간으로 자연스럽게 하기 어려움). B는 눈 뜬 프레임을 캡처하므로 문제 자체가 없음.
- 라이브 카메라는 "프레이밍 + 캡처" UX로 유지. 결과는 정지 이미지 전/후 비교.
- 포트폴리오 공개: 괜찮음. 단 (1) 남의 샵 사진·얼굴은 공개 글에 쓰지 않기(합성 결과도 본인 얼굴만), (2) 숫자는 실제 측정값만, (3) PreView 등 경쟁자가 볼 수 있으니 샵 리스트·영업 스크립트 같은 실행 디테일은 뺄 것.
