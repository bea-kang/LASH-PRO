# 04. 초기 마케팅 계획

## 목표 (첫 3개월)

1. 소비자 체험 1,000회 → 품질·행동 데이터
2. 샵 요청 리드 30개 → 첫 제휴 샵 10곳
3. 공유 루프가 실제로 도는지 확인 (공유 유입 비율)

## 타깃

- **1순위**: 20~30대 여성, 속눈썹 연장 첫 시도 또는 샵을 바꾸려는 사람. 인스타에서 디자인·샵 계정을 이미 찾아둔 상태.
- **2순위**: 웨딩·촬영·행사 앞두고 한 번 하려는 사람 (실패 비용이 커서 미리보기 수요 최고).
- **샵 쪽**: 인스타 팔로워 1~2만 규모의 원장 인플루언서. 이 사람들이 자기 고객에게 쓰게 하면 그게 곧 샵 영업.

## 채널 (의도 vs 발견)

릴스는 **발견** 채널이고 검색은 **의도** 채널. 둘 다 필요.

| 채널 | 역할 | 액션 |
|---|---|---|
| 인스타 릴스 / 틱톡 | 발견, 바이럴 | 주 3~5개 제작. before/after가 콘텐츠 자체 |
| 인스타 해시태그 검색 (#속눈썹연장 #속눈썹디자인 #무쌍속눈썹) | 의도 | 릴스에 해시태그 세팅, 댓글 유도 |
| 네이버 블로그·지식인 | 의도 ("속눈썹 연장 후회", "무쌍 어울리는 속눈썹") | 눈매별 가이드 글 5~10개, 결과 이미지 삽입 |
| 커뮤니티 (뷰티 카페, 에브리타임, 여시 등) | 의도 + 입소문 | 광고 아닌 "이런 거 써봄" 톤. 규칙 확인 필수 |
| 원장 인플루언서 | 샵 영업 + 소비자 도달 | 무료 제공, 자기 디자인으로 릴스 제작 지원 |

## 콘텐츠 3종

1. **내 눈에 N개 입혀보기**: 같은 셀카에 5개 디자인 순서대로. 가장 기본이자 가장 잘 도는 포맷.
2. **눈매별**: "무쌍에 D컬 하면?", "속쌍에 캣아이 하면?" 눈매 고민 검색과 직결.
3. **미리 봤으면**: 실패 후기 → "이렇게 미리 볼 수 있었음". 공감 + 문제 정의.

원칙: 결과가 곧 광고. 서비스 화면 캡처보다 결과 이미지 위주. 워터마크는 작게, 링크는 프로필.

## 바이럴 루프 설계

- 결과 이미지에 워터마크 + 스토리 템플릿 ("나 이 디자인 하면 이럼 👀 너도 해봐") 자동 생성
- 스토리 공유 → 추가 체험 1회 (결제 대신 공유를 통화로 씀)
- 친구 링크로 들어오면 친구도 1회 무료
- 결과 화면에 "이 샵에 입혀보기 요청" → 샵 리드 생성 → 샵이 가입하면 그 샵 고객 전부 무료 → 샵이 자기 채널에 홍보 → 소비자 유입

## 결제 실험 (1,900원)

- 목적: 수익이 아니라 **지불 의사 확인 + 원가 방어**. 1,900원 × 전환 5% = 유저당 95원 → 원가(장당 40~70원)와 비슷. 돈은 안 됨.
- A/B: (A) 1회 무료 + 공유 시 +1 / (B) 1회 무료 + 1,900원 추가. B 결제 전환율이 지불 의사 데이터.
- 결제 조건: 사업자등록 + PG(토스페이먼츠/포트원) 필요, 수수료 ~3.3% + 소액 최소수수료 → 1,900원은 수수료 비중 큼. 1,900원 단품보다 "디자인 3개 비교권 2,900원"이 마진·가치 모두 나음.
- 샵 링크 유입은 무료 → "제휴하면 고객 공짜"가 샵 영업 포인트.

## 시즌

- 웨딩(4~5월, 9~10월), 여름 휴가·물놀이(6~7월, 마스카라 대체 수요), 연말 모임(11~12월), 졸업·입학(2월).
- 릴스 소재를 시즌 2~3주 전에 배치.

## 예산 (월)

| 항목 | 금액 |
|---|---|
| 릴스 부스팅 실험 | 30~50만원 |
| 마이크로 인플루언서 시딩 5~10명 | 0~50만원 (서비스 무료 제공 위주) |
| 원장 인플루언서 5명 | 0원 (무료 제공 + 콘텐츠 제작 지원) |
| 네이버 블로그·커뮤니티 | 0원 (시간) |
| **합계** | **50~100만원** |

## 지표

- 채널별 유입 → 셀카 업로드 → 결과 → 공유/요청/예약 클릭 (퍼널)
- 공유 유입 비율 (전체 유입 중 공유 링크 경유), 바이럴 계수
- 릴스: 저장·공유 수 (좋아요보다 중요)
- 샵 요청 리드 수, 리드→가입 전환

## 주의

- 남의 샵 디자인을 우리가 카탈로그화하지 않는다. 사용자 개인 업로드만 허용, 샵 카탈로그는 샵이 직접 등록.
- 인스타 링크 자동 수집은 약관 리스크. 스크린샷 업로드가 기본.
- 커뮤니티 홍보는 규칙 위반 시 역효과. 톤 조심.
