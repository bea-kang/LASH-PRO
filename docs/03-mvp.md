# 03. MVP

## 검증 순서

| 단계 | 검증할 것 | 만들 것 |
|---|---|---|
| Phase 0 | 품질 가설 | 스크립트 + 테스트셋 (화면 없음) |
| Phase 1 | 소비자 가설 | 모바일 웹: 업로드 → 합성 → 공유 |
| Phase 2 | 샵 가설 | 샵 셀프서브 페이지 + 링크 + 통계 |

## Phase 0: 품질 스파이크 (화면 만들기 전)

- 테스트셋: 눈매 다른 셀카 10장(무쌍/속쌍/겉쌍, 눈꼬리 올라감/처짐, 안경·마스카라 케이스 포함) × 실제 샵 레퍼런스 10장(눈 감은 클로즈업 포함).
- 모델 2~3개 비교 (이미지 편집 모델: Gemini 이미지 계열, FLUX Kontext/2 Edit 등). 각각 원가·시간·품질 기록.
- 방식 비교: (a) 얼굴 전체 편집 vs (b) 눈 영역만 크롭 → 편집 → 원본에 붙이기. (b)가 정체성 보존·원가 모두 유리할 것으로 예상.
- 입력 비교: 사진만 vs 사진 + 태그(컬/길이/볼륨/스타일). 샵 사진이 눈 감은 접사라 태그 없이는 모델이 헷갈릴 가능성 큼.
- 판정 기준: 속눈썹 경험자 5명에게 "이거 실제 시술 결과라고 믿겨요?" 5점 척도. 평균 3.5 미만이면 방식 재검토.
- 산출물: 모델별 비교표, 최적 파이프라인 1개, 장당 원가.

## Phase 1: 소비자 MVP

**포함**
1. 랜딩: 예시 before/after 3개, "내 눈에 입혀보기"
2. 레퍼런스: 샘플 디자인 8~10개(직접 제작) + 사진 업로드(스크린샷)
3. 셀카: 파일 업로드 방식(인앱 브라우저 호환), 촬영 가이드 오버레이, 눈이 안 잡히면 재촬영 요청
4. 합성 결과: before/after 슬라이더, 저장
5. 공유: 스토리용 템플릿 이미지(워터마크 + 서비스 링크)
6. 추가 체험 규칙: 1회 무료 → 공유 시 +1 (결제는 토글로 실험)
7. 동의: 개인정보 처리·국외이전 동의, 타인 사진 금지, "실제 결과와 다를 수 있음"
8. 이벤트 로깅: 진입 → 레퍼런스 선택 → 셀카 업로드 → 결과 → 공유/예약 클릭

**제외**
- 실시간 AR, 네일, 앱, 소비자 계정, 자체 예약, 샵 검색, 결제(실험 토글 외)
- 인스타 링크 자동 수집 (약관·기술 리스크. 붙여넣기는 시도하되 실패 시 스크린샷 안내로 fallback)

## Phase 2: 샵 MVP

1. "이 샵에 입혀보기 요청" 버튼 (Phase 1 결과 화면) → 샵별 요청 카운트 누적 → 영업 리드
2. 샵 가입: 카카오 로그인, 인스타 계정, 디자인 등록(사진 + 태그 + 가격)
3. 샵 링크·QR, 붙일 곳 가이드
4. 샵 링크 유입 고객은 무료·무제한(월 한도 내)
5. 통계 대시보드 (방문/체험/디자인별/예약 클릭)
6. 첫 10곳은 무료, 전환 데이터 수집 후 유료화

## 기술 고려사항

- **눈 영역 크롭 파이프라인**: 얼굴 랜드마크(MediaPipe 등)로 눈 영역 검출 → 크롭 → 편집 모델 → 블렌딩해서 원본 복귀. 얼굴 정체성 보존 + 원가 절감 + 개인정보 최소화(눈 영역만 API로 전송 가능).
- **정직성**: 피부 보정·눈 확대 금지. 실제보다 예쁘게 나오면 컴플레인을 늘리는 도구가 됨.
- **레퍼런스 정규화**: 샵 사진(눈 감은 접사) → 태그로 보강. 등록 시 태그 입력 강제.
- **대기시간**: 10~30초. 로딩 중 콘텐츠, 인기 디자인 1~2개 선생성(원가와 트레이드오프).
- **인앱 브라우저**: 인스타/카톡 인앱에서 getUserMedia 불안정 → `<input type="file" capture>` 방식.
- **원가·악용 방어**: 기기당 일일 한도, 샵당 월 한도, 셀카당 디자인 수 제한, 동일 이미지 캐시.
- **개인정보**: 원본 미저장 or 24시간 삭제, 국외이전 고지, 미성년자, 타인 사진 금지 약관. 출시 전 법률 검토 1회.
- **스택(초안)**: Next.js(모바일 웹) + Supabase(DB/Auth/Storage) + 이미지 편집 API + Vercel. 분석은 GA4 or Mixpanel 무료 티어.

## 성공 지표

- 품질: 경험자 평가 평균 ≥ 3.5/5
- 소비자: 랜딩→셀카 업로드율 ≥ 25%, 체험 완료율 ≥ 80%, 공유율 ≥ 10%, 예약/요청 클릭률 ≥ 15%
- 샵: 10곳 중 7곳이 링크를 실제로 붙임, 2주 후에도 디자인 추가·통계 확인, "고객이 이 화면 들고 왔어요" 발화
