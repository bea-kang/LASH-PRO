- [ ] 샵용 고도화 아이디어 (아래 후보에서 고르기)

## 샵용 고도화 후보 (아직 미정)

1. **요청 리드**: "이 샵에 입혀보기 요청" 수를 샵에 알림 → 가입 유도. 가장 먼저.
2. **상담 링크**: 고객이 입혀본 결과 + 셀카를 샵 카톡으로 바로 전송 → 원장이 "가능/불가/이렇게 조정" 답변. 상담 시간 단축.
3. **디자인 통계**: 가장 많이 입혀본 디자인 → 인스타 콘텐츠 기획 재료.
4. **리터치 리마인드**: 3~4주 주기 재방문 알림 (일본식 재방문 관리).
5. **예약 확정 메시지 삽입**: "시술 전 디자인 다시 확인하기" 링크 → 노쇼·변경 감소.
6. **아카데미 제휴**: 교육생이 배우는 디자인을 툴에 등록 → 개업 시 자동 사용.
