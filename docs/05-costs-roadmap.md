# 05. 예상 비용 & 로드맵

인건비 제외. 2026-09 기준 추정이며 API 가격은 변동 → Phase 0에서 실측.

## 변동비 (체험 1회당)

| 항목 | 단가 | 비고 |
|---|---|---|
| 이미지 편집 API | 40~70원 (FLUX Kontext ~$0.04, Gemini Flash 이미지 ~$0.04~0.05) / 고품질 모델 ~180원 ($0.13) | 눈 영역 크롭으로 해상도 낮추면 절감 |
| 얼굴 랜드마크 | 0원 | 클라이언트 or 서버 오픈소스 |
| 스토리지·전송 | ~1원 | 24시간 삭제 시 미미 |
| **체험 1회** | **약 50~80원** (고품질 모델 시 ~200원) | |

- 월 5,000회 → 25~40만원. 월 20,000회 → 100~160만원.
- 소비자 무료 체험은 순수 마케팅 비용. 샵 200회 플랜(29,000원) 원가는 1~1.6만원 → 마진 45~65%. 고품질 모델을 쓰면 적자 → 한도·모델 선택이 마진을 결정.

## 일회성

| 항목 | 금액 |
|---|---|
| 사업자등록 | 0원 (결제 실험·PG 가입 전 필요) |
| 개인정보처리방침·약관 법률 검토 | 30~50만원 (템플릿 후 검토) |
| 상표 출원 (서비스명) | 20~40만원 |
| 테스트셋 제작 (셀카 촬영 협조, 소정 사례) | 0~20만원 |
| A 방식 가닥 에셋 (컬 3종 × 길이, 외주 시) | 0~50만원 |

## 3개월 총액 (대략)

- Phase 0~1 (품질 + 소비자 MVP + 마케팅): 변동비 ~50만원 + 고정 ~5만원 + 일회성 ~80만원 + 마케팅 150~300만원 ≈ **300~450만원**
- 인건비·개발 외주 제외. 개발은 직접 + AI 코딩 전제.

## 로드맵

### Phase 0 — 품질 검증 (2주)
- [ ] 테스트셋 (셀카 10 × 레퍼런스 10)
- [ ] A 스파이크: MediaPipe + Three.js 실시간 가닥 렌더링 (컬 1종, 길이 3단계)
- [ ] B 스파이크: 카메라 자동 캡처 → 눈 크롭 → 모델 2~3개 × 입력(사진/사진+태그) 비교
- [ ] 레퍼런스 → 래시 맵 번역 정확도 (캡션에 스펙 적힌 게시물 20~30개를 정답지로 비교)
- [ ] 경험자 5명 평가 → 3.5/5 이상인 파이프라인 1개 확정, 장당 원가 실측
- [ ] 유저 인터뷰 5명: 고민 지점, 셀카 업로드 저항, 얼마면 낼지
- [ ] 서비스명·도메인·인스타 계정 확보
- Go/No-go: 품질 미달이면 방식 재검토 (파라미터 기반 실시간 AR로 전환 등)

### Phase 1 — 소비자 MVP + 콘텐츠 (4~6주)
- [ ] 모바일 웹 (업로드→합성→공유), 동의·약관, 이벤트 로깅
- [ ] 샘플 디자인 8~10개 제작
- [ ] 릴스 10개 선제작 후 런칭, 네이버 글 5개
- [ ] 결제/공유 A/B 실험
- 목표: 체험 1,000회, 셀카 업로드율 25%, 공유율 10%

### Phase 2 — 샵 MVP (6~10주)
- [ ] "이 샵에 입혀보기 요청" → 리드 누적
- [ ] 샵 셀프서브 (카카오 로그인, 디자인 등록, 링크·QR, 통계)
- [ ] 원장 인플루언서 5명 + 리드 상위 샵 → 첫 10곳 무료 온보딩
- 목표: 10곳 중 7곳 링크 실제 부착, 예약 클릭 데이터 확보

### Phase 3 — 유료화 & 확장 (3개월~)
- [ ] 29,000원 플랜 출시 (무료/유료 구분, 한도, 통계)
- [ ] 전환 데이터로 영업 자료 ("체험 고객 예약 전환 N%")
- [ ] 아카데미·재료상 제휴 검토
- [ ] 네일 추가 검토 (같은 샵 업셀)
- [ ] 일본 준비: 살롱 온보딩 채널(LINE·핫페퍼 외부 링크 정책) 조사, 일본어 UI

## 리스크

| 리스크 | 대응 |
|---|---|
| 품질이 "내 눈" 같지 않음 | Phase 0에서 걸러냄. 눈 크롭 + 태그 보강. 안 되면 파라미터 AR로 피벗 |
| PreView가 속눈썹 추가 | 속눈썹 레퍼런스 샵 10곳 선점, 소비자 트래픽 확보 |
| 셀카 업로드 저항 | 눈 영역만 저장 고지, 24시간 삭제, 예시로 신뢰 |
| 원가 폭주 | 한도·캐시·크롭 해상도 |
| 소비자 결제 저조 | 예상된 결과. 공유 루프로 대체, 샵 수익에 집중 |
| 개인정보·국외이전 | 출시 전 검토, 동의 UI |
